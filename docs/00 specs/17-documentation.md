## Documentation

Documentation must not mirror source code, scripts, or Makefiles. It may mention them only briefly and without snippets, and must remain valid unless substantial code changes require an update.

Document only stable, high-level concepts and user-facing outcomes; omit command behavior, implementation mechanisms, file paths, defaults, generated artifacts, rationale, and step-by-step details. If a normal implementation change could make text inaccurate, it does not belong in the documentation.
